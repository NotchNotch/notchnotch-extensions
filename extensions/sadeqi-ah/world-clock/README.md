# World Clock

The time in the cities you work with, one glance away.

## How it works

- List time zones in **Setup**, such as `America/New_York, Europe/London, Asia/Tokyo`.
- Hover over the notch to see each city's time, whether it's today or tomorrow there, and how far ahead or behind it is.
- A moon marks cities where it's night.

## Privacy

Works offline; it uses your Mac's time zone data.
