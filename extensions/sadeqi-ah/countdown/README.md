# Countdown

Count down the days to a launch, a trip or a deadline.

## How it works

- Set the event and its date in **Setup**, such as `2027-03-14` or `2027-03-14 09:00`.
- Hover over the notch to see the days left; on the last day it counts hours, minutes and seconds. Turn on **Show Beside the Notch** to keep it next to the camera.
- When the moment comes, the notch tells you.

## Privacy

Works offline.
