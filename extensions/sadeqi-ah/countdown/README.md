# Countdown

Count down the days to a launch, a trip or a deadline.

## How it works

- Set the event and its date in **Setup**, such as `2027-03-14` or `2027-03-14 09:00`.
- Days left sit beside the camera; on the last day it counts hours, minutes and seconds.
- When the moment comes, the notch tells you.

## Privacy

Works offline.
