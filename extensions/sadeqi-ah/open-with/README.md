# Open With

Drop files on the notch and pick the app that opens them.

## How it works

- Drag files or folders to the notch and let go on **Open With**. The notch shows the apps that open all of them, the default app first; pick one, or **Other…** to choose any app. (Before NotchNotch 0.14.1, they show as a menu.)
- Open With keeps nothing: once the menu has the files, it forgets them.
- It shows only while you drag something it takes; it has no activity in Home.

Open With asks for nothing and makes no network requests. It never sees where your files are, only their names. Needs NotchNotch 0.14 or later. Built with NotchNotch SDK 0.14.
