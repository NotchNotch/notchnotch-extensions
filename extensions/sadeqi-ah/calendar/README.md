# Calendar

Your next event in the notch, with a live countdown and a button to join the meeting.

## Set up

1. Open **Setup** and choose **Connect Calendar**.
2. Allow Calendar to read your calendars.
3. When macOS asks, allow access to your calendars.

It uses the accounts already in the Calendar app, such as iCloud, Google or Exchange. There is nothing else to sign in to.

## Use it

- Choose which calendars to show in **Setup**.
- The notch shows a countdown before your next event.
- **Join** opens the meeting link when the event has one.

NotchNotch only reads your calendars. If events don't appear, check **System Settings › Privacy & Security › Calendars** and reconnect from **Setup**.
