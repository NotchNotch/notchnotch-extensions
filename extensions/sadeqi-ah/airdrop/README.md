# AirDrop

Drop files on the notch to send them with AirDrop, without keeping them anywhere.

## How it works

- Drag files or folders to the notch and let go on **AirDrop**. The AirDrop sheet opens with them; pick a person or device.
- AirDrop keeps nothing: once the sheet has the files, it forgets them.
- It shows only while you drag something it takes; it has no activity in Home.

AirDrop asks for nothing and makes no network requests. It never sees where your files are, only their names. Needs NotchNotch 0.14 or later. Built with NotchNotch SDK 0.14.
