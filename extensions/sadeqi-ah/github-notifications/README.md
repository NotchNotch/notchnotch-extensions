# GitHub Notifications

Your unread GitHub notifications, with the count beside the notch.

## How it works

- Create a [classic personal access token](https://github.com/settings/tokens/new?scopes=notifications&description=NotchNotch) with the **notifications** scope and paste it in **Setup**. It's stored in your Keychain.
- The unread count appears beside the camera when there's something new. Hover to see the latest threads; click one to open it.
- New notifications are announced below the notch.

## Privacy

Reaches only `api.github.com`, as often as GitHub's `X-Poll-Interval` allows.
