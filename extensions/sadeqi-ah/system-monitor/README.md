# System Monitor

CPU, memory, disk and network at a glance, and a heads-up when your Mac is working hard.

## How it works

- Hover over the notch to see CPU, memory and disk as rings, and network speed down and up.
- When the CPU stays busy, memory fills up or your Mac runs hot, the notch lets you know and keeps the CPU ring in the wings until things calm down. Brief spikes don't count. Turn this off under Setup.
- Memory is counted the way Activity Monitor's "Memory Used" counts it; disk is your startup disk.

NotchNotch reads your Mac itself, every two seconds while System Monitor runs, so it asks for nothing and makes no network requests. Needs NotchNotch 0.11 or later. Built with NotchNotch SDK 0.11.
